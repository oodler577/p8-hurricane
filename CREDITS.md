# Original program and author

**p8-hurricane is based on _Skipper Jim's Hurricane Tracking Chart_ by James R. Brown.**

Brown's original Commodore 64 program let users record weather bulletins, replay a storm's path across a map, and see its distance from coastal cities. That program is the foundation and inspiration for this recreation. Its name and its author's name deserve prominent credit wherever this project is presented.

This project carries that experience forward with new Prog8 source. The supplied HF.GILBERT observations were extracted unchanged from the original disk. The application code is new Prog8 source. The map artwork is adapted from the original disk's HUR1 graphics, with its coastline, filled land and grid retained. It is converted to a two-colour-per-cell hires bitmap and compressed into the PRG. The new title screen follows the original's large lettering and orange/cyan presentation. No original executable code is included. See data/artwork/provenance.json for the original graphics SHA-256 and transformation details.

The original title and author must remain visible in every platform build, including C64 PAL, C64 NTSC, and any future Commander X16 version. Keep the shared in-program credit, README, release descriptions, and distributed documentation consistent.

The original program's embedded instructions identify its author as **James R. Brown**. No publication year has been established from the inspected copy.
